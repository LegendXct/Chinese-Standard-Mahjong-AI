# RL 收口记录(2026-06-30)

**结论:自对弈 PPO(含 KL 锚 M5、信用分配、运气基线预案)对 M5 的【当前架构 + 特征】已近 argmax 天花板,继续投不划算。后续靠架构/特征/数据。** 本文档留档"为什么停 RL",证据三方收敛。Round-1 保底 `rl_v1_B` 全程未动。

## 一、RL 全过程(gen2 阶段二,src/rl/sync 同步 PPO,从 M5 起,KL 锚 M5)

| 步 | 做法 | 结果(arena vs M5,argmax 1v3,@500) |
|---|---|---|
| Step 2 | 终局零和奖励 score/30(稀疏)+ β_kl 扫 0.02/0.1/0.5 | **−0.4 ~ −0.8**:稀疏终局奖励退化,信用分配是天花板 |
| Step 3 | 改信用分配:fanback(时间再分配)/ potential(向听势能塑形),β_kl=0.5 | 救回 parity:fanback **+0.22** / potential **+0.30**(翻正号但 <2SE) |
| Step 4 | 放大 3.5×(385 轮)长 potential + combo(fanback⊕potential) | **放大不涨**:回落 ~0;+0.30 实为噪声高位(300 组 SE~0.48 的"先升后崩"是假象);真实效应 ~0~+0.15 |

详见 `results/gen2_stage2_iter.md`。最佳候选 `rl_s3_potential`/`rl_s4_combo` 均 +0.3~+0.4(≤1SE)。

## 二、Arena 尺子审计(详见 docs/arena_audit.md)

排除"尺子低估 RL"的可能:
- **argmax(部署口径)下 RL 对 M5 / M3' / rule / v1 / 多样场全部打平**(多样场 RL 6.71/7.08 vs M5 6.96,≪SE)。
- **偏离探针**:RL 的 argmax 与 M5 在 **97.6% 决策上相同**,~⅔ 整局逐决策与纯 M5 一字不差 → 有效样本 ~30%。
- **温度扫**:RL−M5 配对差随 T 升高变正(T=1.0 时 +2.47),**但是低熵抗噪混淆**(PPO 削尖 logits,同温度下低熵策略退化更轻),argmax 不可兑现。
- 标尺:一个 SL 世代(M3'→M5,GELU)= +4.42;RL 的 ~0–0.4 是噪声级。

## 三、Path A 运气基线 R² gate(详见 scripts/path_a_gate.py / results/path_a_gate.json)

判别"parity = 信噪比(运气掩盖) vs 真天花板":同架构同训练、唯一差异=完美信息(对手当前手牌+牌墙构成+各家向听)喂入,预测某座位终局 score/30(12000 局人类牌谱重放,按局切分,早停取 peak val R²):
- obs-only R²=**0.0695** / perfect-info R²=**0.0796** → **控表征增量 = +0.010**(< 预提交 +0.05 线)。
- 参照:M5 价值头 R²=0.204(真实 obs 上限,从头训小网受过拟合限只到 0.07)。
- **结构原因**:obs 的 `CH_UNSEEN` 已编码"每种牌未见总数(=对手手牌+牌墙合计)",完美信息只是拆成"谁持哪张",对终局预测边际价值极小;终局更由**未来摸牌(牌墙顺序)**决定,静态隐藏信息扣不掉它。
- caveat(已记录,不影响结论):从头网偏弱;gate 用牌墙构成非顺序(人类数据近似)。但三方证据收敛,自对弈+全牌墙复核被判低价值(arena 已证 argmax 无空间兑现)。

## 四、已采纳的后续实验规范(重要,下次直接用)

- **主判据 = 多样场 argmax**:候选 vs `{rule, M3', M5}`,门槛 = **显著超过 M5 多样场 +6.96 的 2SE(即 >~+1.3)**。部署相关、真实、自带同场 M5 基准。
- **廉价前置 = 偏离探针**(`src/arena/deviation_probe.py`):候选对基座 argmax 偏离 **<~5% → 判"没做事"**,免跑。
- **样本量 ≥500 组**才可信(Step4 教训:300 组 SE~0.48 会读出假"先升后崩")。
- **不要用温度/随机评测当 gate**(低熵抗噪混淆);**不要只信 1v3-vs-M5**(70% 重复局、不灵敏)。
