# Arena 尺子审计(2026-06-30)

**目的**:验证 Step 2–4 用的评测尺子 `argmax + 1v3-vs-冻结M5 + 复式同墙配对差` 是否**系统性低估 RL** 的改进——若低估,Step 2–4 "RL 仅达 parity / M5 近天花板"的结论可能误杀有效方法。

**底线结论**:**没有低估【可部署(argmax)棋力】**。argmax 口径下 RL 与 M5 在所有对手场(M5/M3'/rule/v1/多样场)**全部打平**;温度升高时 RL−M5 配对差变正,但那是**低熵抗噪混淆**,部署用 argmax 不可兑现。`1v3-vs-M5` 这把尺**不灵敏**(70% 重复局),但"不灵敏"≠"低估"。

口径:全部 `--seed 80640`、`--groups 500`(2000 候选局/run)、复式四座轮换、配对差 = 候选每局 `score − others_mean`(零和下 = 4/3·score)按组平均。脚本 `src/arena/run_audit.sh`;原始产物 `results/arena_audit/*.md`、`logs/audit_*.log`。

## 本次新增的评测基础设施(`src/arena/`)

老 `argmax 1v3` 路径**字节级不变**(M5 vs M3' 精确复现 +4.421);新增均为**可选参数**,不传即老行为:
- `duplicate.py` / `run_arena.py`:`--temperature T`(对称套候选+对手)、`--opponents a,b,c`(异质三对手)、`--indep-opp`(三对手座位各自独立采样 rng、共享 model)、`--decision-salt`(改采样种子不改墙,同墙复测)。
- `policies.py`:`NNPolicy*.clone_shared()`(共享 model、独立 rng)。
- `deviation_probe.py`(只读分析):统计候选 argmax 与纯 M5 逐决策偏离率、零偏离局占比、仅偏离/零偏离局配对差。

## Test#4 标定阶梯(argmax,定标尺)

| 对位 | 同墙配对差 | 含义 |
|---|---|---|
| **M5 vs M3'** | **+4.421 ± 0.753** | 一个 SL 世代(GELU 跳变),金标精确复现 |
| M5 vs v1(sl_B_gn) | +5.990 ± 0.765 | M5 比初代强 ~6 |
| M3' vs v1 | +0.731 ± 0.733 | v1 ≈ M3'(头对头仅 +0.73) |
| M5 vs rule | +15.238 ± 0.897 | rule 在 M5 下方 ~15 |
| M3' vs rule | +10.727 ± 0.919 | — |

**尺度:一个 SL 世代 ≈ +4.4。** RL 对 M5 的 +0.30 只有【一个世代的 7%】(噪声级);+1.5 ≈ ⅓ 世代(真实温和目标)。

## Test#2 轨迹偏离(argmax,候选 vs 纯 M5)

| 候选 | 零偏离局 | 决策偏离率 | 全体配对差 | 仅偏离局 | 仅零偏离局 |
|---|---|---|---|---|---|
| rl_s3_potential | **70.5%** (1409/2000) | **2.43%** | +0.301±0.34 | −3.60±1.42 | +1.94±1.02 |
| rl_s4_combo | **65.6%** (1312/2000) | **2.94%** | +0.400±0.39 | −2.06±1.40 | +1.69±1.05 |

RL 的 argmax 与 M5 在 **97.6% 决策上完全相同**;~⅔ 整局逐决策与纯 M5 一字不差 → **有效独立样本 ~30%(≈600 局)**,±0.34 的 SE 被大量"M5 克隆局"摊薄、偏乐观。偏离局 −3.6 / 零偏离局 +1.9 的劈叉是**选择性 + 零和记账假象**(`配对差=4/3·score`,RL 更常在本就要输的局偏离),不能读成"RL 一改就变差";净效应看全体 +0.30(<1SE,与 0 不可分)。

## Test#1 温度对称扫(RL vs M5,`--indep-opp`,2 salt 均值)

| T | s3pot | s4combo |
|---|---|---|
| 0(argmax) | +0.301±0.34 | +0.400±0.39 |
| 0.3 | +0.31 (0.83/−0.22) | +0.05 (0.70/−0.61) |
| 0.6 | +0.51 (0.94/0.08) | +0.17 (0.89/−0.54) |
| 1.0 | **+2.47** (2.40/2.55) | **+1.35** (1.03/1.66) |

字面:差值随 T 升高变正。**但只有 T=1.0(近随机打)才清晰为正;T=0.3/0.6 仍 ~0(salt 间正负翻转=噪声)。** 这是**低熵抗噪混淆**:Test#2 证 argmax 排序 97.6% 不变 → RL 没换更好的选择,只是 PPO 把 logits 削尖(熵更低);同温度 T 下低熵策略被随机化更轻 → T=1.0 赢。**部署用 argmax,此分布差不可兑现**(连 T=0.3 都无收益)。

## Test#3 真实多样 / 弱对手场(argmax)

| 候选 | vs {rule,M3',M5} | vs rule | vs v1 |
|---|---|---|---|
| rl_s3_potential | +6.707±0.669 | +15.150 | +5.975 |
| rl_s4_combo | +7.079±0.668 | +15.801 | +5.665 |
| **M5(基准)** | **+6.961±0.638** | +15.238 | +5.990 |

**多样 argmax 场:RL 与 M5 严格打平**(s3pot −0.25、s4combo +0.12,均 ≪ SE);vs rule、vs v1 同样打平。无"RL 更强/更稳",无非传递性翻盘。

## 结论(逐问)

1. **argmax 是否掩盖 RL 优势?** 字面温度增益存在,**但是低熵抗噪混淆、非排序棋力**(argmax 97.6% 相同 + 多样场打平 + 只在 T=1.0 显)。对 argmax 部署:**无被掩盖的棋力**。
2. **有效样本/SE?** 实打实偏低:66–70% 克隆局,有效样本 ~30%,SE 偏乐观——但这只让 +0.30 更不可信地 >0,不制造隐藏的赢。
3. **多样场?** RL ≈ M5(6.71/7.08 vs 6.96)。
4. **尺度?** 一世代 +4.4;RL 的 ~0–0.4 是噪声,远够不着 +1.5。
5. **"M5 近天花板"几分真?** **几乎全真**——argmax 下 RL 对所有对手打平,偏离探针证 RL 只动 2.4% 决策。尺子没低估可部署 RL;唯一真问题是 `1v3-vs-M5` 不灵敏(非低估)。

## 对后续 RL 评测 gate 的建议

- **主判据 = 多样场 argmax**(候选 vs `{rule, M3', M5}`),门槛 = **显著超过 M5 自身多样场 +6.96(>2SE,即 >~+1.3)**。部署相关、真实、自带同场 M5 基准,远胜 `1v3-vs-M5`。
- **廉价前置 = 偏离探针**:候选对基座决策偏离 <~5% → 判"没做事",免跑。
- **不要用**温度/随机评测当 gate(熵混淆);**不要只信** `1v3-vs-M5-argmax`(70% 重复局、不灵敏)。
