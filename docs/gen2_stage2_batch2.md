## 0. 立题:第一批证伪了什么 + 第二批做什么

第一批(rl_v2/rl_v2b/rl_v2c)确定性结论:**单步番数奖励 `r += α·(fan/8)^pow · 1[和牌]` 是信用分配天花板。**
- 参数全扫过:线性(α 0.3→0.6)、非线性(pow 1→3)、封顶(cap24)——comp_mean 平台在 **0.34–0.35 不动**(rl_v2c 200 upd 无增益),自对弈 avg_fan 平 **~13.5**。
- **根因是结构(信用分配),非参数**:做大牌需要**早期布局**(吃/碰改变手牌结构、定向弃牌、保留种子牌),但单步奖励只在**和牌瞬间**给信号。
- **为什么现有 GAE 还不够**:配置 `gamma=1.0`,理论上终局番数无折扣传到每步——但**信号淹没在方差里**(绝大多数局不以大牌结束,MC 回报方差极大,early 布局动作的优势信号相对噪声太小,学不出来)。这是高方差下的长程信用分配问题。

**第二批 = 番数敏感的攻守双塑形**(用户明确目标):
- **进攻侧(§2 fan backward)**:把终局高番的信用反向定向分配到早期布局决策 → 学会做大牌。
- **防守侧(§3 番数敏感点炮罚)**:点炮惩罚随对方和牌番数**非线性放大** → 学会"宁可点小炮也绝不放大牌"。这是 RL 奖励能表达、SL 做不到的番数敏感防守。
- 两侧都对番数敏感、方向一致(重视番数),理论不冲突,但需评测确认无副作用(§4)。

## 1. 起始 ckpt:从 rl_v2c eval-best 续训(不从 M5 重来)

**建议:`checkpoints/rl_v2c_evalbest_0345.pt`(upd252,comp_mean 0.345)续训。**

理由:
- rl_v2c 已是**稳健均衡基座**(vs 所有强对手不输、vs-M5 ~0、点炮 0.17、不过拟合)。双塑形是在其上"加攻守番数敏感",**无需重建稳健性**。
- 从 M5 重来会丢掉第一批已兑现的稳健化(KL 锚 + 地板把 vs-M5 −0.27→~0 救回),等于重走弯路。
- 风险对冲:第二批**仍带 KL 锚 M5(0.10)+ 地板**(§5),即使塑形把策略往激进推,KL 锚保证不偏离 M5 太远。
- 回退基线全留:M5 本身、rl_v2b(+0.414)、rl_v2c(0.345)。**Round-1 保底 rl_v1_B 绝不动。**

## 2. 进攻侧:fan backward(番数反向信用分配)

**核心**:终局和牌的番数,沿**和牌方**决策轨迹**反向折扣分配**,让促成大牌的早期决策(吃/碰/杠、定向弃牌、留牌)按时间邻近度拿到信用。

### 2.1 实现层:叠加在 GAE 上的 shaped advantage(不替代)
- 基础 RL 信号不变:`score/30` + GAE → `A_gae`(保住赢/输/点炮信用,第一批已验证有效)。
- fan backward 作为额外项,合成 **`A = A_gae + c_fb · Â_fb`**(`Â_fb` batch 内标准化)。
- 为何叠加而非替代:GAE 是无偏赢输信用不能丢;`A_fb` 是**有意的做大牌偏置**(§2.4),用小 `c_fb` + KL 锚 + score reward 兜住不跑飞。

### 2.2 A_fb 构造
和牌方轨迹,和牌在第 `T` 步、终局番数 `fan`,第 `t` 步(距和牌 `k=T−t`):
- **`fb(t) = γ_fb^k · g(fan)`**,`g(fan)` 用非线性突出高番(沿用第一批已验证能集中 advantage 的 `(fan/8)²` 或阈值)。
- 点炮/被点不做 fan backward(防守由 §3 处理)。

### 2.3 对哪些决策反传
- **第一版**:和牌方全部决策步按 `γ_fb^k` 折扣反传(不分动作类型),先验证机制本身有没有用。
- **第二版**(若有效):对结构性决策(吃/碰/杠、定向弃牌)加权,过渡步小权重。

### 2.4 只对高番和牌反传(建议)
- **仅 `fan ≥ fb_min_fan`(如 ≥12 番)的和牌做 fan backward**;低番和牌只走 score+GAE。
- 理由:8 番快胡布局不值得强化,甚至与做大牌**冲突**(快胡 vs 做大牌两套路线)。阈值把信用集中到真正大牌通路。

### 2.5 方差与偏置
- 方差:`c_fb` 从小起(0.3);`Â_fb` 归一化;value head 更大 warmup。
- 偏置:非势能 shaping 会改变最优策略——**这正是要的有意偏置**;`c_fb` 上界 + KL 锚 + score reward 三重兜底。偏太狠则降 `c_fb` 或回退势能型(Φ=向听/番势能,策略不变但信用更弱)。

## 3. 防守侧:番数敏感点炮惩罚(躲大炮)

**目标(用户明确)**:不只少点炮,而是**特别避免放对方和大牌**。RL 奖励能表达番数敏感防守,SL 做不到。

**当前**:`r -= β·(fan_opp/8)` 线性(`fan_opp`=对方和牌番数)。问题:点小番 vs 点大番的惩罚梯度不够陡,没有"宁可点小炮也别放大炮"的强信号。

**改为非线性放大**:
- **选项 A(幂)**:`r -= β·(min(fan_opp, cap)/8)^p_def`,`p_def`=1.5 或 2.0。点大番罚远重于点小番,与进攻侧 `(fan/8)²` 对称、好调。
- **选项 B(分段阈值)**:`fan_opp<8` 轻罚、`≥阈值(16/24)` 重罚。更可控、更贴"躲大炮"直觉。
- **建议起步:选项 A `p_def=2.0`**(与进攻侧对称),实测看大番点炮频率;需要更硬"躲大炮"再切分段。
- **封顶**:对方番可能极大(十三幺 88 番),`fan_opp` cap 至 24/32 防单局巨额负奖励炸方差。
- 点炮判定沿用第一批已对齐裁判语义的检测(argmin reward 向量识别放铳方;自摸无放铳方)。
- 结构对称:这是对**点炮方**轨迹的惩罚塑形(与 fan backward 只塑形和牌方对称),仍叠加在 score+GAE 上。

## 4. 攻守平衡(潜在冲突与权衡)

两侧都重视番数、方向一致,理论不冲突。但**必须在评测量化潜在副作用**:
- **风险**:追高番时为进张弃牌更冒险 → **自己点炮的大番可能上升**(搏大牌副作用)。
- **监控**:fan backward 开启后,大番点炮(≥16)频率 + 点炮平均番是否抬升(§6 诊断)。
- **若冲突**:调两侧相对权重(进攻 `c_fb` vs 防守 `β/p_def`);或对"搏大牌局"额外加防守约束。
- **方法**:先两侧都开跑,**从评测量化冲突再平衡**(而非先验假设无冲突)。

## 5. 保留第一批的稳健保护(已验证有效,续用)

- **KL 锚 M5 `kl_sl_coef=0.10`**:护对强者基本盘,防双塑形把策略推太激进而 vs-M5 恶化。
- **eval-best 地板 `eval_floor_se=0.5`**:只入选对每个强对手不明显输的候选。
- **多样化对手池**(自快照 + M5 锚 + bighand + def + rl_v1b):防过拟合。
- **点炮总率红线 base+3pp 自动压**:仍在(与 §3 的番数敏感罚互补:红线管总率底线,§3 管番数结构)。

## 6. 成功标准(第二批 DoD)

**进攻**:
- ⭐ **平均番真正上升**:突破第一批 **13.5 平台**(目标自对弈 avg_fan ≥14.5);以 **arena 口径胜局平均番**(§7 需新增)确认候选显著高于 rl_v2c。

**防守(番数分段看点炮,不只看总率)**:
- ⭐ **大番点炮频率显著下降**:点炮按番数分段统计,**≥16 番点炮频率显著低于 rl_v2c**——**哪怕总点炮率持平**(宁可多点小炮、少放大炮)。
- 点炮平均番下降。

**稳健底线**:
- vs-M5 不恶化(comp 子集 vs-M5 ≥ rl_v2c ~0,不回 ≤ −0.2)。
- comp_mean 不低于 0.345。
- 点炮总率不破 base+3pp 红线。

**机制验证(诊断)**:早期结构性决策(吃碰/定向弃牌)频率随 fan backward 变化;点炮番数分布随 §3 左移 → 确认是机制起作用而非又一个平台。

## 7. 实现改动点(代码,待审定后开写)

**进攻 fan backward**:
- `env_worker.py`/`finish_game`:保留和牌方每步轨迹引用 + 终局 `fan`;算 `fb(t)` 反向分配。
- `common.py`:traj `_STEP_FIELDS` 加 `is_winner_traj`、`steps_to_win`。
- `train_rl.py`(GAE 合成):`A = A_gae + c_fb · normalize(A_fb)`。
- `config.py`:`fan_backward_coef`(c_fb)、`fan_backward_gamma`(γ_fb,起 0.9)、`fan_backward_min_fan`(起 12)、`fan_backward_action_weights`(第二版)。
