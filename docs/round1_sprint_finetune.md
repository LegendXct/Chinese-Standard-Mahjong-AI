# Round 1 冲刺:进攻导向短时微调(设计+估算,未开机)

诊断依据(我方 35 场天梯对局的聚合统计):胜率 11%(同桌均值 ~27%)、胡牌平均番 10、点炮 31%、
被自摸+担底 ~63%。核心短板是**做牌慢、很少自己胡**(进攻不足),次为对强对手
读危险牌不足(点炮高)。本方案只设计与估算,**等 item 1 的 A/B 结果与本估算后由用户决定是否开机**。

## 1. 进攻导向奖励塑形

从 rl_v1(last.pt)热启动,PPO 配置沿用 M3(KL 锚定 0.05 防崩、clip 0.15、
熵 0.01),奖励在原终局得分基础上加塑形项:

```
r_i = score_i / 30                                   # 原终局奖励(主导)
    + A_HU   · 1[i 和牌]                              # 主动和牌奖励
    - A_MISS · 1[i 未和 且 终局时 i 听牌(shanten≤0)] # "听了没和上"惩罚
    - A_DEAL · 1[i 点炮]                              # 点炮额外惩罚(防点炮率反弹)
```

- 系数(score/30 量级参考:一次普通和牌 score≈(8+番) → /30 ≈ 0.5~1.0):
  - **A_HU = 0.30**(显著但不压过真实分;鼓励"把牌做成"而非保平)
  - **A_MISS = 0.15**(惩罚消极:听牌却被别人先和,逼迫提速/抢和)
  - **A_DEAL = 0.20**(塑形进攻易致点炮反弹,这一项是安全阀;点炮本已被负分罚过,这里加码)
- 退火:A_HU 从 0.30 线性退火到 0.10(前 1/3 训练期),避免后期为奖励硬冲、偏离真实分最优。
- 监控(每次完整评测):胡率(目标↑)、点炮率(红线:不得显著高于 rl_v1 基线)、
  平均番、vs SL 配对差(红线:不得跌破 0)。点炮率涨破基线 +5pp 即降 A_HU/升 A_DEAL。

### 训练侧改动点
- `src/env_fixed.py`:终局时暴露每家 `final_shanten`(hands 已知,调 shanten_useful_wait)。
- `src/rl/env_worker.py`:轨迹的终局 reward 注入 A_HU/A_MISS/A_DEAL(和牌者/听牌未和/点炮者由 env 终局信息判定)。
- `src/rl/train_rl.py`:新增 `--set reward_hu=0.30 reward_miss=0.15 reward_deal=0.20` 与退火;GAE/PPO 不变。
- 其余(共享内存 arena、KL 再锚定、阶梯控制器)全部复用。

## 2. 见效估算(基于 M3 实测)

- M3 节奏:~45s/update、~18 games/s;lr 升档(upd 1073)等单一改动的评测响应在 **~100~200 update 内显现**。
- 从 rl_v1 热启动 + 直接的 +0.30 和牌奖励,策略梯度会**直接**偏向和牌动作,
  预计 **~150~300 update(约 2~4h)** 内镜像胡率从 ~0.25 起动,可能升到 0.28~0.33。
- 8~12h(~640~960 update)足够让胡率移动并初步稳定,并跑出 2~3 个完整评测点判定方向。
- **诚实预期**:这是**温和、不确定**的提升,不是补齐对天梯头部 11 分差距的解药。
  天梯强 bot 做牌更快,短微调最多把我们从"远逊"拉到"接近",大改靠 gen2 三周全量。

## 4. 风险与回退
- 保底 = 已上线 rl_v1_B,**全程不动**;微调产物是"挑战者",仅在终选**显著更强且点炮不反弹**时才换装。
- 微调可能不收敛/退化:8h 内若评测跌破 vs SL 0 线或点炮率涨破 +5pp,放弃微调,维持保底。
- 有卡开机本身不破坏数据盘;A/B 与训练都在挑战者权重上做,保底权重(dist/rl_v1_B.fp16.pt + 已上传)不受影响。
